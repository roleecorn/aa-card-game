# 神惱

## Source grounding

本角色採用卡奧斯原案、並經 PintBox 明確認可的版本。

- Stats：`Text 1 / Design 1 / AA 0`。
- Stress 上限：2。
- `設定狂`：每回合一次，可以少 1 顆 Text 骰，換取額外 1 顆 Design 骰。
- `自己做`：自己不能受到任何正面或負面的修正；原討論明確列舉技能、Event Card、Coordination Card。
- 討論沒有明確定義作品適性，因此不自行補適性。

## Canonical runtime rules

- `設定狂` 是每回合一次的 active skill：選擇自己一顆 pending Text die，移除該骰後立即額外擲 1 顆 Design die。
- 若沒有自己的 pending Text die，技能不可使用。
- `自己做` 只封鎖來自其他技能與卡牌的角色修正；正常工作 / 摸魚造成的 Stress 變化不屬外部修正。
- member-target Event / Coordination Card 不能選神惱。
- 外部 Stress 修正取消；其他角色對神惱 pending die 的修改取消。
- 神惱自己的技能仍可改變自己的狀態與骰子。

## Visual brief

原始討論沒有 source-backed 外貌設定；以下為 Prototype art direction。

- 核心印象：高度專注於設定、拒絕外部干涉、自己埋頭完成。
- 單人 portrait；銀白長髮、偏冷色工作室、周圍是大量無文字的草圖紙、幾何模型與便條紙形狀。
- 表情專注偏執，視線集中在手邊創作，不與外界互動。
- 不包含任何可閱讀文字、Logo、UI、卡框或數值。
- 標準 portrait 768×1024 WebP；compact 384×320 WebP，獨立構圖。
